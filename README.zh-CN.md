# 布谷（Cuckoo）

<!-- @Sdrop 布谷(Cuckoo) v1 © 2026 Xingdrop -->

布谷——如布谷鸟般从不误时，温柔守护你的每日作息。

**Cuckoo — gentle, on-time reminders like the cuckoo's call.**

> 📄 许可：**商业用途须书面授权**（PolyForm 风格商业许可，详见 [LICENSE](./LICENSE)）；授权联系与申请模板见 [CONTACT.md](./CONTACT.md)。
> 🛡 漏洞报告：见 [SECURITY.md](./SECURITY.md)（私密报告 + 响应时间承诺）。
> 📝 变更记录：[CHANGELOG.md](./CHANGELOG.md)。

布谷是一个开源、移动优先的健康提醒 PWA（可装到手机桌面），并提供可选的 Android APK：帮你按时吃药、喝足水、开会间隙起身活动、把微习惯坚持下去，家人也能在你身后盯着你。

## ✨ 特性

- **社交社区**：帖子图文/视频分享、评论点赞收藏、一键加入计划、个人主页与关注、官方计划与亲友频道
- **语音 / AI 助手**：点按底部按钮说话即可操作 App，也可切换成**打字输入**。使用你自己填写的 OpenAI 兼容 API 密钥（仅存本机），每次请求先生成可核对的**预案**（动作清单 + 参数），确认后才执行，支持多轮对话与执行历史撤回
- **多分类提醒**：吃药 / 喝水 / 锻炼 / 休息 / 工作 / 自定义，支持每日多时间点、每周/每月、间隔循环与**不定时**提醒；全屏提醒浮层支持「延迟」「跳过」；拍照打卡挑战
- **健康数据看板**：完成率、连续天数、分类统计、喝水进度（达成当日目标记 1 次）
- **用药管理**：库存自动扣减、低库存预警、服药历史（按日/周/月筛选）
- **运动与专注**：微运动库（13 个跟练动作，多帧图解可滑动；一键带图预填新建提醒）、番茄钟（默认 25+5 可自定义）
- **我的计划**：自建/加入/官方计划，一键发帖，计划内提醒可修改（显示来源与「已修改」标记）
- **消息通知**：站内通知中心 + Web Push（到期 / 漏服 / 低库存三类触发源）；Android 端另用精确闹钟保证锁屏准点响铃
- **周报/月报**：月报热力图、分类统计、环比与建议；**成就系统**：不间断坚持、用药/锻炼/喝水达人
- **亲友协作**：邀请码绑定家人（需对方同意）、只读健康摘要、图文聊天、紧急联系人提醒（**仅站内通知**，未内置短信服务商）
- **离线优先**：游客模式与离线账户无需服务器即可使用，登录后自动合并到云端
- **多主题**：内置 3 套主题（蜜桃暖阳 / 青翠晨露 / 冰岛蓝湾），设置页随时切换
- **隐私与安全**：数据按账户隔离、数据导出与注销、登录限流与锁定、上传三重校验、审计日志；生产环境若未配置强 `JWT_SECRET` 会**拒绝启动**
- **多端**：Web PWA（离线可用）+ Android APK（设置页内可下载最新安装包）

## 🚀 快速启动

要求：Node.js 22+（CI 与本地开发使用 Node 24；jsdom 单测依赖较新的 undici）。

```bash
# 后端
cd backend
cp .env.example .env      # 配置 JWT_SECRET 等
npm install
npm start                 # 接口  http://localhost:3000/api/v1
                          # 文档  http://localhost:3000/api   （Swagger，仅非生产环境）

# 前端（另开终端）
cd frontend
npm install
npm run dev               # http://localhost:5173
```

> Web Push 需在 `backend/.env` 配置 VAPID 密钥对（见 `.env.example`）。
> 生产部署（Nginx + PM2 + 备份）说明随项目内部文档维护。要点：后端构建**必须带 dev 依赖**（`npm ci && npm run build`），再把 `dist/` 与仅生产依赖的 `node_modules` 同步到运行机，并显式设置 `NODE_ENV`、`JWT_SECRET`、`CORS_ORIGINS`、`UPLOAD_DIR`。生产环境下若 `JWT_SECRET` 缺失、仍是默认值或短于 32 字符，进程会立即退出。

## 🧰 技术栈

前端：React 19 + TypeScript + Vite + Tailwind CSS v4 + Zustand + React Router 7（PWA 离线可用）
后端：NestJS 11 + TypeORM + better-sqlite3（WAL）+ JWT + Swagger + class-validator + Web Push + 定时任务
移动端：Capacitor 8（Android），含 4 个自研原生插件（精确闹钟 / 语音识别 / 离线语音 / 照片保存）

## 📸 功能详解

以下截图均来自真实运行的布谷演示账号，全部为演示数据，不含真实用户信息；AI 密钥输入框为掩码显示。

### 🌱 社交社区

![社区](./docs/images/features/social.png)

- 五个频道：**广场 / 关注 / 我的 / 官方计划 / 亲友**；右上角「发布」支持图文与视频。
- 帖子可**点赞、评论、收藏**，也可以「**一键加入计划**」——把别人的计划保存到「我的计划」，打开计划开关即生成对应提醒。
- 点他人头像进入个人主页，可查看他的公开帖子并关注；顶部铃铛显示未读通知数，数字实时更新。
- 「官方计划」集中展示可直接加入的模板，「亲友」频道只显示已绑定家人的动态。

### 🎙 语音 / AI 助手

先看配置与输入方式：

![语音助手设置](./docs/images/features/assistant-settings.png)

- 入口在「设置 → 语音助手」：打开开关后，今日页底部才会出现语音按钮。
- 需要填写 **AI API 地址**（OpenAI 兼容，如 `https://api.openai.com/v1`）、**API 密钥**与**模型名**（如 `gpt-4o-mini`、`deepseek-chat`）。
- 密钥只保存在本机浏览器存储中，**不会上传布谷服务器**；输入框始终以掩码显示。
- 「测试连接」会立即发一次真实请求，成功时弹窗返回模型的自我介绍，失败时给出具体错误。

两种输入方式，同一条处理链路：

![打字输入](./docs/images/features/assistant-typing.png)

- 底部悬浮按钮默认是「点按说话」：点一次开始录音，再点一次结束（不再需要长按）。
- 点按钮右侧的**小键盘图标**即可切换成「点按打字」，按钮随之变成「点按打字」；该选择仅保存在本机，下次打开继续生效。
- 语音识别在浏览器走 Web Speech API，在 APK 走自研 `NativeSpeech`（常驻识别器，无缝续听；无系统识别服务的机型自动降级到离线 `NativeVosk`，飞行模式也能识别）。
- 识别不准、环境嘈杂或浏览器不支持语音时，直接用打字输入，后续流程完全一致。

**第一步：生成预案，不直接执行**

![预案确认](./docs/images/features/assistant-plan.png)

- 一句话可以包含多件事：助手会把它拆成多个动作（每次最多 5 项），逐条列出「将要」做什么以及关键参数，例如「标题：喝水 200ml · 时间：07:00 · 重复：daily · 分类：water」。
- 识别/输入的文字显示在可编辑文本框里：识别有误可直接改字后点「↻ 重新解析」，也可以点「🎤 接着说」补充一句，再一起重新解析。
- 在确认前不会对账户做任何修改；点「取消」即放弃本次预案。
- 可执行的动作覆盖：新建 / 完成 / 延迟 / 跳过 / 删除 / 启停提醒，记录喝水，切换提醒通知、响铃、震动，以及跳转页面；社交类动作只会说明、不会执行。

**第二步：确认后逐条汇报结果**

![执行结果](./docs/images/features/assistant-result.png)

- 点「确认执行（N 项）」后逐条执行，结果面板按「识别 → 修改 → 结果」三段展示，成功项带 ✅ 与具体结果（如「已创建每天 07:00 的『喝水 200ml』提醒」）。
- 失败项会单独给出原因，不影响其他已成功的动作。
- 底部可选择「继续对话」（携带上下文）或「新对话」（清空上下文）。

**第三步：执行历史可回溯、可撤回**

![语音执行历史](./docs/images/features/assistant-history.png)

- 今日页头部的 🎤 按钮打开执行历史，记录每次任务的时间、原话、理解结果与逐条执行结果。
- 已执行的多步任务可以「↩ 撤回此任务」，按逆序撤销（例如删除刚创建的提醒），撤回后标记「已撤回」。
- 勾选某几条记录后点「接着说」，会只携带所选记录作为上下文；底部「清空」需二次确认才执行。
- 历史只保存**已执行**的任务，取消的预案不会入库。

> 语音识别在浏览器中需要 HTTPS 环境；打字输入不受此限制。

### 🔐 登录与账户

![登录页](./docs/images/features/login.png)

- 注册用户名 **2–24 位**，支持中文、字母、数字、下划线（`_`）与连字符（`-`）；登录 / 注册在同一页面切换，注册成功即自动登录。
- **先以游客身份体验**：不连服务器也能完整使用（数据仅存本机），之后注册登录时自动把本地数据合并到云端。
- 登录接口带**限流与失败锁定**；生产环境若 `JWT_SECRET` 缺失、仍是默认值或短于 32 位，进程会拒绝启动。
- 页面底部固定提供「隐私政策与健康免责声明」入口。

### 🏠 今日看板

![今日看板](./docs/images/features/today.png)

- 顶部是可**左右切换日期**的日历条（含农历），回到今天时显示「今天」标记。
- **完成率卡片**：显示今日已完成 / 总数、错过数、连续坚持天数；「选择」可勾选哪些提醒计入完成率（例如把喝水达标算作一次完成），「统计」直达完整数据看板。
- **喝水卡片**：显示今日已喝 / 每日目标与剩余量，点「+200」快速记一笔。
- **当日提醒**：按时间排序，多时间点提醒会折叠成一张卡片并列出「已完成 / 未提醒 / 已错过」；**不定时提醒**单独显示 ✓ / × 一目了然；错过或已完成的提醒可展开补记。
- 右上角三个入口：统计、语音执行历史、设置。

### ⏰ 提醒管理

![提醒列表](./docs/images/features/reminders.png)

- 「服务与管理」折叠区内是四宫格快捷入口：**药物管理 / 喝水管理 / 锻炼库 / 番茄钟**，下方为**我的计划**。
- 「全部提醒」折叠分区中按时间展示每条提醒的**分类图标、标题、重复规则与下一次时间**，右侧状态为「启用中」。
- 每条提醒可直接**编辑 / 删除 / 停用**，无需进入详情页；停用后不计入完成率，也不触发通知。

### ➕ 新建 / 编辑提醒

![新建提醒](./docs/images/features/reminder-new.png)

- **分类**：吃药、锻炼、喝水、休息、工作、自定义（直接决定图标与统计口径）。
- **提醒时间可加多个**：每个时间点独立触发；勾选「不定时」则每天提醒一次、不显示具体时刻。
- **重复规则**：单次、每天、每周、每月、自定义间隔（按天/周/月循环）。
- **内容说明**可选：文字说明、图片（最多 9 张）、视频、外部链接（B 站 / 文档 / 网页等，提醒时点击直接跳转）。
- 选择「喝水」分类时会出现水量设置，配合每日目标自动累计。
- 保存后立刻出现在今日看板与提醒列表，并按规则参与通知调度。

### 💧 喝水管理

![喝水管理](./docs/images/features/water-settings.png)

- 展示今日进度条与已喝 / 目标值，随时快速记录。
- 可设置**每次喝水量**与**每日目标**，两者都会作用于看板上的快捷记录按钮。
- 可一键新建喝水提醒（多时间点），到点提醒时点一下即完成并自动累计水量。
- 喝水提醒即使被删除，也仍然可以手动记录水量；当日达成目标可计入完成率（在今日看板「选择」中配置）。

### 💊 用药管理

![用药管理](./docs/images/features/medicines.png)

- 药品卡片显示名称、剂量与用法（如「1 片 · 随餐 · 早餐后服用」），库存不足时显示**「库存不足」**标签。
- 四个快捷操作：**服用一次**（按设定扣减库存并写入服药记录）、**补充库存**、**编辑**、**历史**。
- 历史页按日 / 周 / 月筛选，完整记录每次服药时间、数量与是否补记。
- 添加药品时可设置库存、低库存阈值、有效期、用药说明与多张药品照片；低库存会触发站内通知（并可通过 Web Push 推送）。

### 🤸 微运动库

![微运动库](./docs/images/features/exercises.png)

- 内置 **13 个跟练动作**，按拉伸 / 提肛 / 颈部等分组，每个动作标注建议时长（20 秒 – 2 分钟）。
- 每个动作有多帧图解，可左右滑动查看分解步骤（适合久坐间隙做）。
- 「**+ 加入计划**」会带着该动作与整组图片跳到新建提醒页，保存后到点即可跟着做。

### 🍅 番茄钟

![番茄钟](./docs/images/features/pomodoro.png)

- 专注 / 休息两种模式切换，默认 25 分钟专注 + 5 分钟休息。
- 专注与休息时长都可自定义（如 50+10 深度工作、15+3 入门），结束后自动进入下一段循环。
- 页面底部提供节奏建议，帮助按自己的注意力周期微调。

### 🎯 我的计划

![我的计划](./docs/images/features/plans.png)

- 支持**新建自建计划**、从社区**一键加入**他人计划，以及使用官方计划模板。
- 计划卡片显示提醒数量与启用状态，开关可整体启停计划内所有提醒。
- 操作：**添加提醒**（新提醒自动归属该计划）、**一键发帖**（把计划分享到社区）、**重命名**、**删除**（计划下的全部提醒会一并删除）。
- 计划内的提醒在提醒列表中会显示来源与「已修改」标记，便于区分原创与二次调整。

### 📊 数据统计

![统计](./docs/images/features/stats.png)

- 顶部橙色卡片汇总：连续坚持天数、今日完成率、今日喝水进度。
- **月热力图**：按日展示完成率，颜色由浅到深表示强度，可切换月份。
- **近 7 天趋势**柱状图，以及按分类的完成情况明细，用来发现「哪一类总在掉队」。

### 📅 周报 / 月报

![报告列表](./docs/images/features/reports.png)

![周报详情](./docs/images/features/report-detail.png)

- 周报可在页面右上角**一键生成**；每周一 08:00 与每月 1 日 08:00 还会自动为所有账户生成，并各推一条站内通知。
- 报告详情包含：周期完成率与**环比变化**、**亮点**（最佳分类、完成最多的一条提醒）、**分类统计**（每类完成数 / 计划数与占比）以及一条针对性建议。
- 历史报告全部保留，可随时回看任意一周 / 一月。

### 🏆 成就墙

![成就墙](./docs/images/features/achievements.png)

- 顶部展示累计数据：连续天数、用药完成次数、喝水完成次数。
- **7 条成就规则**：七日坚持、月度铁人、百日筑基、年度之王、用药达人、锻炼标兵、喝水高手。
- 每条成就都有实时进度条，达成后自动点亮，是长期坚持的可视化反馈。

### 👨‍👩‍👧 亲友协作

![亲友](./docs/images/features/family.png)

- **邀请码双向绑定**：生成 6 位邀请码（24 小时内有效）发给家人；对方在「TA 的邀请码」中提交后，需你确认才完成绑定。
- 绑定后可以查看彼此**只读**的提醒完成情况、照片记录与药品库存，并可在亲友频道**图文聊天**。
- **漏服 / 库存通知联系人**：提醒超时未完成或药品库存不足时通知指定联系人（仅站内通知，未内置短信服务商）。

### 🔔 通知中心

![通知](./docs/images/features/notifications.png)

- 汇总全部站内通知：提醒到期、漏服、低库存、报告生成、亲友动态等。
- 未读用小红点标记，右上角「全部已读」一键清空；单条可点击跳转到对应页面。
- 配合 **Web Push**（VAPID）可在浏览器关闭时推送；Android 端则使用**精确闹钟**，锁屏也能准点响铃。

### ⚙️ 设置与主题

![设置](./docs/images/features/settings.png)

- **主题外观**：蜜桃暖阳 / 青翠晨露 / 冰岛蓝湾三套主题，随时切换并立即生效。
- **通知偏好**：提醒通知、响铃、震动、是否显示「跳过」按钮逐项开关。
- **后台提醒排查指引**：内置各品牌机型的电池优化 / 自启动 / 后台锁定设置说明，避免提醒被系统静默杀掉。
- 账户区可退出登录；还可进行数据导出、账号注销、查看隐私政策与下载 Android 安装包。

### 📱 Android 应用

- 后端提供最新安装包：`GET /api/v1/app/download`（App 内「设置」页也有入口，仅 App 内可见）。
- 语音识别为**自研实现**：`NativeSpeech` 常驻一个识别器实现无缝续听；在无系统 `RecognitionService` 的机型（如 ColorOS）自动降级到 `NativeVosk`——内置离线中文模型，飞行模式下也能识别。
- 未使用 `@capacitor-community/speech-recognition`：它每次启动都销毁重建识别器，会丢开头几个字。
