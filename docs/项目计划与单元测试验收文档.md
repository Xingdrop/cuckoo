## 2. 开发规范与协作约定

| 项 | 约定 |
|---|---|
| 分支 | `main`（可发布）/ `dev`（集成）/ `feature/*` |
| 提交 | Conventional Commits（feat/fix/test/docs/chore） |
| 代码检查 | 后端 ESLint + Prettier；前端 ESLint + Prettier；提交前 lint |
| 类型 | TypeScript `strict: true`，前后端共享类型（`frontend/src/types` 与后端 DTO 对齐） |
| 文档 | **每次新增可转移参数必须更新 `.env.example` 与《技术方案设计.md》§9** |
| 评审 | 每个里程碑结束走 `requesting-code-review` skill 做代码评审；页面走 `ui-review` 视觉评审 |
| 测试先行 | 纯逻辑（调度/统计/事务）先写单测再实现（TDD 节奏） |

### 3.1 后端 Jest 单元测试

#### 3.1.1 提醒调度算法（reminders.scheduler.spec）

| 编号 | 用例 | 输入 | 预期 | 状态 |
|---|---|---|---|---|
| UT-SCH-01 | 单次提醒 | once, start=今日 18:00 | next=18:00 | ☐ |
| UT-SCH-02 | 每天 | daily, 今日 08:00 | 明日 08:00 | ☐ |
| UT-SCH-03 | 每 N 天 | interval=3 | 3 天后同时刻 | ☐ |
| UT-SCH-04 | 每周多选 | weekly [Mon,Wed,Fri]，当前 Tue | 最近 Wed 同时刻 | ☐ |
| UT-SCH-05 | 每月固定日 | monthly day=15 | 下月 15 日 | ☐ |
| UT-SCH-06 | 每月 31 日到 2 月 | monthly day=31, from=1/31 | 2 月最后一天 | ☐ |
| UT-SCH-07 | 每 N 小时 | interval=6 | +6h | ☐ |
| UT-SCH-08 | 已过时间跳过 | from 晚于当天触发点 | 计算到下一周期 | ☐ |
| UT-SCH-09 | endDate 边界 | 触发点 = endDate | 不产生 next | ☐ |
| UT-SCH-10 | 时区处理 | 用户时区 UTC+8 | 按本地 08:00 折算 UTC | ☐ |
